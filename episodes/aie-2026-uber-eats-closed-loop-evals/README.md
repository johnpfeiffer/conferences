## How this was produced

1. `get-transcript` skill: caption/audio fetches bot-gated from the working IP on
   2026-08-27 (full ladder documented in COMPARISON.md) → server-side watch-page
   fetch captured metadata + flattened full text (kept as
   `youtube_raw_untimestamped.txt`) → the android-client gate lifted the same
   session and yt-dlp pulled the json3 caption track, the info.json, and the
   audio (kept in /tmp during the session) → json3 converted to the repo raw
   format. Speaker spellings verified against the conference's own
   speakers.json and the video description (see glossary sources).
2. `fix-transcript` skill: suspicious-token scan + context resolution → 12 rules
   (2 panel-format marker-spanning fixes embed the marker line in the observed
   string) → deterministic apply → residual gate (0 observed strings remain in
   the fixed body; the raw header's documentation of the ASR renderings is
   deliberately untouched).

## Reproduce

```bash
python3 ../../.agents/skills/fix-transcript/scripts/apply_transcript_fixes.py \

```
